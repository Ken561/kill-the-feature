# Assumptions

**Classification: Portfolio scenario.** Stated explicitly since no real data collection occurred for this exercise.

## Assumptions Underlying the Sizing

1. The proportion of meetings that are "low-stakes status" versus "decision-making" versus "sensitive" roughly follows patterns typical of a large enterprise organization — this exercise doesn't have access to real meeting-type distribution data.
2. Teams that have already adopted an existing transcription tool represent a meaningful share of the organization, reducing the addressable population for a new, separate feature.
3. Employees' stated reluctance to have sensitive meetings automatically recorded is a reliable proxy for actual behavior, not just a stated preference that wouldn't hold in practice.
4. The cost estimates in the [Cost Analysis](../decision-memo/decision.md) reflect typical enterprise implementation patterns for a feature of this scope, not a vendor quote for a specific tool.

## Why Name These as Assumptions

If any of these assumptions turn out to be wrong — for instance, if very few teams have actually adopted existing transcription tools — the sizing conclusion could change. Naming the assumptions explicitly means the decision can be revisited on the basis of real data, rather than the reasoning being locked inside an unstated premise.
